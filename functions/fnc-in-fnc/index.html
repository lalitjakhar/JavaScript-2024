Function Inside Function

Define helper functions inside another function — they're private and only visible to the outer function.

Why nested? Organize code, hide implementation details, and create closures (coming in advanced topics).

1. Basic nested function

function app() { const greet = () => { return "Hello World"; }; console.log(greet()); }
Result…

2. Multiple inner functions

function app() { const addTwo = (a, b) => a + b; const multiply = (a, b) => a * b; console.log(addTwo(2, 4)); console.log(multiply(2, 4)); }
Result…

3. Helper functions example

Inner functions can help organize complex logic.

function calculate(x, y) { const square = n => n * n; const sum = (a, b) => a + b; return sum(square(x), square(y)); }
Result…

4. Scope reminder

Inner functions are not accessible outside the outer function. They're private helpers.

function app() { const helper = () => "I'm private"; return helper(); } // helper(); // ❌ ReferenceError

This encapsulation is powerful — keeps global scope clean!
