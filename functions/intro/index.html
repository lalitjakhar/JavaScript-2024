Step 4 · Functions

Functions — reusable recipes

A function is a reusable recipe. Give it inputs (parameters), it does work, and can give back a result (return).

Why functions? Write the logic once. Call it whenever you need — with different inputs each time.

1. Call a simple function

function singHappyBirthday() { return "Happy Birthday To You..."; }
Result…

2. Inputs → output

Parameters are the ingredients. Return is the dish.

function add(a, b) { return a + b; }
Result…

3. Return true / false

function isEven(n) { return n % 2 === 0; }
Result…

Without return, a function gives undefined.
