Step 4 · Functions

Callback Functions

Pass a function as an argument to another function. The receiving function "calls it back" later.

Why callbacks? Handle async operations, events, and custom behaviors. Core of map, filter, forEach.

1. Basic callback

function greet() { return "Hello!"; } function callFunc(fn) { return fn(); // Call the passed function } callFunc(greet);
Result…

2. Callback with map

Pass a function to map — it calls it for each item.

const nums = [1, 2, 3, 4]; const doubled = nums.map(n => n * 2);
Result…

3. Custom operation

Pass different functions to do different things.

function operate(a, b, operation) { return operation(a, b); } operate(5, 3, (x, y) => x + y); // 8 operate(5, 3, (x, y) => x * y); // 15
Result…

4. Real-world: event listeners

button.addEventListener("click", () => { console.log("Clicked!"); });

The arrow function is a callback — called when the event fires!
