Arrow Functions

A shorter syntax for function expressions: () => { } — cleaner, modern, and everywhere in React.

Why arrows? Less typing, implicit return for one-liners, and cleaner callbacks (map, filter, etc.).

1. Expression vs Arrow

Expression

const greet = function() { return "Hi!"; };

Arrow

const greet = () => { return "Hi!"; };

2. No parameters

const singHappyBirthday = () => { return "Happy Birthday To You..."; };
Result…

3. With parameters

const sumTwoNumbers = (a, b) => { return a + b; };
Result…

4. Implicit return (one-liner)

Skip braces and return for single expressions.

const isEven = (n) => n % 2 === 0;
Result…

One parameter? You can skip parentheses: n => n * 2

5. Arrow in array methods

Super clean with map, filter, etc.
