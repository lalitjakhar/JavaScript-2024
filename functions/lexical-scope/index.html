Step 4 · Functions

Lexical Scope

A function can see variables from its parent scope — determined by where it's written, not where it's called.

Why lexical? Inner functions inherit outer variables — the foundation of closures and private data.

1. Inner function sees outer

function outer() { const message = "Hello"; function inner() { console.log(message); // Can see message! } inner(); }
Result…

2. Nearest variable wins

If inner and outer both have the same variable, inner wins.

function myApp() { const myVar = "outer"; function myFunc() { const myVar = "inner"; console.log(myVar); // "inner" } myFunc(); console.log(myVar); // "outer" }

3. Chain of scopes

Functions look up through parent scopes until they find the variable.

const global = "I'm global"; function outer() { const outerVar = "I'm outer"; function inner() { console.log(global); // from global console.log(outerVar); // from outer } inner(); }

4. Scope is by position, not call

Where the function is written determines its scope, not where it's called.

const x = 10; function show() { console.log(x); // Sees x = 10 } function caller() { const x = 20; show(); // Still logs 10, not 20! }
