Parameter Destructuring

Extract object properties directly in function parameters: function greet({ name, age }) { } — super clean in React!

Why destructure params? No need to write obj.name repeatedly. Very common in React components: ({ props }).

1. Without destructuring

function printDetails(person) { console.log(person.firstName); console.log(person.gender); }
Result…

2. With destructuring

function printDetails({ firstName, gender }) { console.log(firstName); console.log(gender); }
Result…

4. Default values in destructuring
