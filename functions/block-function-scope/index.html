Block & Function Scope

let and const are block-scoped ({ }). var is function-scoped — visible everywhere in the function.

Why scope matters? Prevents variable collisions and keeps data safe. Block scope is modern and safer.

1. Block scope (let/const)

Variables inside { } don't leak out.

{ let name = "Jakhar"; console.log(name); // "Jakhar" } console.log(name); // ❌ ReferenceError
Result…

2. Function scope (var)

var ignores blocks, only respects functions.

if (true) { var name = "Jakhar"; } console.log(name); // "Jakhar" — leaks out!
Result…

3. var inside function

var stays inside the function, visible to all blocks.

function myApp() { if (true) { var firstName = "jakhar"; } console.log(firstName); // Works! var is function-scoped }
Result…

4. Best practice: use let/const

let and const prevent bugs by keeping variables in tight scopes. Avoid var in modern JS.

// Modern JS for (let i = 0; i < 3; i++) { console.log(i); } // i is not available here ✅
