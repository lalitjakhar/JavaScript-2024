Step 4 · Functions

Function Expressions

Store a function in a variable: const greet = function() { ... } — useful for passing functions around.

Why expressions? Treat functions like values — assign to variables, pass to other functions, return from functions.

1. Declaration vs Expression

Declaration

function greet() { return "Hi!"; }

Expression

const greet = function() { return "Hi!"; };

2. Simple expression

const singHappyBirthday = function() { return "Happy Birthday To You..."; };
