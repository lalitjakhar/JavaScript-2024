Rest Parameters

Collect all remaining arguments into an array: function sum(...numbers) { } — unlimited parameters!

Why rest? Handle unknown number of arguments. Perfect for sum, join, or list operations.

1. Basic rest parameter

function myFunc(a, b, ...rest) { console.log("a:", a); console.log("b:", b); console.log("rest:", rest); // array of remaining }

2. Sum all numbers

function addAll(...numbers) { let total = 0; for (let n of numbers) { total += n; } return total; }

3. Rest must be last

You can only have one rest parameter, and it must come last.

// ✅ Valid function fn(a, b, ...rest) { } // ❌ Invalid function fn(...rest, a, b) { }

Rest parameter is always an array, even if empty.

4. Combine with regular params

function greet(greeting, ...names) { return names.map(n => `${greeting}, ${n}!`); }
