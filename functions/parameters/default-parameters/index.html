Step 4 · Functions

Default Parameters

Give parameters a fallback value: function greet(name = "Guest") { ... } — no more undefined errors!

Why defaults? Handle missing arguments gracefully. No need for if (param === undefined) checks.

1. Without default

Missing argument becomes undefined.

function add(a, b) { return a + b; } add(5); // 5 + undefined = NaN
Result…

2. With default parameter

function add(a, b = 0) { return a + b; } add(5); // 5 + 0 = 5
Result…

3. Multiple defaults

function greet(name = "Guest", message = "Hello") { return `${message}, ${name}!`; }
Result…

4. Old way (before ES6)

function add(a, b) { if (typeof b === "undefined") { b = 0; } return a + b; }

Default parameters are cleaner and more readable!
