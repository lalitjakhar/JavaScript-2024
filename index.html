What is JavaScript?

JavaScript is a programming language — a way to give a computer clear instructions. On the web, those instructions make a page do things: react to clicks, update text, check forms, and load data.

If you’ve never coded

Think of a recipe. Ingredients are your data (names, numbers, lists). Steps are your instructions (“if the score is high, show a win message”). JavaScript is how you write that recipe so the browser can follow it.

What you can make it do

  • Remember — store a name, score, or shopping list
  • Decide — if password is correct → let the user in
  • Repeat — show every item in a list
  • Change the page — swap text, show/hide a box
  • Wait — load weather or posts from the internet

Tiny example — day one

// 1) remember a value
const name = "Lalit";

// 2) show it
console.log("Hello, " + name);

Mental model

Only 6 ideas to start

Don’t try to learn “all of JavaScript” at once. Almost every program is these six ideas mixed together.

  1. 01

    Values

    Raw pieces of data: text "hi", number 25, yes/no true.

  2. 02

    Variables

    Named boxes that hold values — const name = "Lalit". Prefer const; use let only when it must change.

  3. 03

    Decisions & loops

    if picks a path. Loops repeat work so you don’t copy-paste the same line 50 times.

  4. 04

    Functions

    A reusable recipe: write once, call whenever you need greet, add, check, or calculate.

  5. 05

    Lists & objects

    Arrays = ordered lists. Objects = labeled details like { name, age }. Real apps are full of both.

  6. 06

    Page + waiting

    DOM = talk to buttons and text on the page. Async = wait for slow work (timers, internet) without freezing everything.

Save time

Beginner rules that matter

Keep these near you for the first few weeks. They prevent most early bugs.

Spelling is strict
Name and name are different. One wrong letter and the program fails.
Quotes mean text
"42" is text. 42 is a number. Mixing them causes weird results.
Use ===
Prefer === for comparisons. It checks value and type — fewer surprises than ==.
Start with const
Default to const. Switch to let only when you must reassign later.
Read the first error line
Errors look scary. The top line usually gives the file and exact line number.
Go in order
Basics → arrays → objects → functions → then the harder topics. Skipping early steps slows you down later.
