JavaScript = electricity & switches

Your full learning path

Follow top to bottom. Each step has a simple meaning and a place to practice.

01 Basics Words, numbers, yes/no, loops

In plain English: how to store values, ask questions with if, and repeat with loops.

You will be able to: print messages, check age, count from 1 to 10.

variables (visual) if-else (visual) for loop (visual) console.log
02 Arrays Lists of many values

In plain English: one variable holding many items — names, scores, products.

You will be able to: add/remove items, double every number, keep only even ones.

intro (visual) push-pop map filter reduce
03 Objects Named details about one thing

In plain English: a person has a name, age, city — objects store related info together.

intro iterate destructuring
04 Functions Write once, reuse forever

In plain English: a recipe for a task. Give ingredients (inputs), get a dish (return value).

intro arrow functions callbacks
05 How JS works Why order & hoisting matter

In plain English: how the computer reads your code — helpful when something looks “weird.”

open lesson
06 Set, Map & chaining Unique lists & safe access

In plain English: Set = unique items. Map = fancy key→value box. ?. = don’t crash if missing.

Set Map optional chaining
07 OOP Objects with methods & this

In plain English: blueprint for making many similar objects (like many users from one class).

this prototype getters / setters
08 Errors Catch problems safely

In plain English: when something breaks, catch it and show a friendly message instead of crashing.

try / catch
09 Async JS Wait for data without freezing

In plain English: some work takes time (API calls). Promises & async/await let you wait cleanly.

promises async / await fetch

In plain English: connect buttons and forms to your JS — build a todo app.

  2. Open the lesson file and change one line. Refresh.
  3. Open Console (Cmd + Option + J (Mac) or Ctrl + Shift + J (Windows).
  4. Do a challenge in exercises/ before the next topic.
