What is JavaScript?

JavaScript is a programming language that makes web pages interactive. HTML structures a page. CSS styles it. JavaScript makes it do things — respond to clicks, update content, fetch data, and run logic.

In plain words

You write instructions. The browser (or Node.js) reads them and runs them. Those instructions can store values, make decisions, repeat work, talk to servers, and change what the user sees.

Created for

Browsers — to add behavior to websites. Today it also powers servers (Node.js), mobile apps, desktop apps, and tooling.

How it runs

Line by line (mostly). Modern JS supports modules, async work, and class-based OOP. You do not compile it first like C++ — the engine interprets / JIT-compiles it live.

Core idea

Store data → make decisions → reuse code with functions → work with lists & objects → update the page (DOM) → handle waiting (async).

The building blocks

Every JavaScript program is built from a small set of ideas. Master these and you can read almost any JS code.

  1. 01

    Values & types

    Numbers, strings, booleans, null, undefined, BigInt, Symbol — plus objects and arrays (reference types).

  2. 02

    Variables

    Named boxes: const (preferred), let (when you must reassign), avoid var unless learning history.

  3. 03

    Operators & control flow

    Math and comparisons, then if / else, switch, loops, break / continue.

  4. 04

    Functions

    Reusable recipes — declarations, expressions, arrows, callbacks, scope, and hoisting.

  5. 05

    Objects & arrays

    Structured data. Objects hold named properties. Arrays hold ordered lists. Methods like map, filter, reduce transform them.

  6. 06

    Async & the DOM

    Promises and async/await wait for data. The DOM API lets you select elements, listen to events, and build UIs.

Key facts to remember

Case-sensitive
Name and name are different.
Semicolons
Optional in many places (ASI), but clear statements help. Prefer consistency.
=== not ==
Use strict equality so types are not silently converted.
Mutable vs reassign
const blocks reassignment, not mutation of objects / arrays inside.
Everything is an object? Almost
Primitives are not objects, but they can behave like they have methods via temporary wrappers.
Single-threaded + event loop
One main call stack. Async work is scheduled; the event loop picks up callbacks when the stack is free.
