Arrow Functions — lexical this

Arrow functions () => {} don't have their own this. They inherit this from the surrounding scope.

Rule: Arrow functions capture this from where they're defined, not where they're called. Great for callbacks, but don't use them as object methods.

Arrow function as method (problem)

const user1 = { firstName: "Lalit", age: 18, about: () => { // Arrow takes `this` from outer scope (window) return `${this.firstName}, age ${this.age}`; } }; user1.about(); // undefined, undefined

When to use arrow functions

Good: Callbacks, timers, array methods. They keep the outer this.

const counter = { count: 0, start() { setInterval(() => { this.count++; // Arrow keeps counter's `this` console.log(this.count); }, 1000); } };

Avoid: Arrow functions as object methods. Use regular functions or shorthand methods instead.
