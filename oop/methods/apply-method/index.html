apply() — like call(), but with an array

func.apply(thisArg, [arg1, arg2, ...]) is identical to call(), except arguments are passed as an array.

When to use: If you already have arguments in an array, apply() is cleaner than spreading them into call().

Using apply() with an array

const user1 = { firstName: "Lalit", age: 18, about(hobby, favMusician) { return `${this.firstName}, age ${this.age}, likes ${hobby} and ${favMusician}`; } }; const user2 = { firstName: "Jakhar", age: 12 }; const args = ["guitar", "bach"]; user1.about.apply(user2, args);
