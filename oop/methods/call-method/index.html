call() — borrow methods with custom this

func.call(thisArg, arg1, arg2, ...) calls func and sets this to thisArg. Extra arguments are passed individually.

Use case: Borrow a method from one object and use it with another's data. Great for reusing logic without copying code.

Borrowing a method

const user1 = { firstName: "Lalit", age: 18, about(hobby, favMusician) { return `${this.firstName}, age ${this.age}, likes ${hobby} and ${favMusician}`; } }; const user2 = { firstName: "Jakhar", age: 12 }; // Borrow user1.about for user2 user1.about.call(user2, "guitar", "mozart");

call() executes immediately. Compare with bind() which returns a new function.
