bind() — create a new function with locked this

func.bind(thisArg, arg1, arg2, ...) returns a new function with this permanently set to thisArg. Call it later.

Use case: Pass methods as callbacks (event handlers, timers) without losing this. Unlike call() or apply(), bind() doesn't execute immediately.

Creating a bound function

const user1 = { firstName: "Lalit", age: 18, about(hobby, favMusician) { return `${this.firstName}, age ${this.age}, likes ${hobby} and ${favMusician}`; } }; const user2 = { firstName: "Jakhar", age: 12 }; const func = user1.about.bind(user2, "guitar", "bach"); func(); // Now safe to call anywhere
