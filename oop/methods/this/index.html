this — dynamic context

this refers to the object that called the method. It's determined at call time, not when the function is defined.

Rule: obj.method() → inside method, this is obj. If you call a function without an object, this is undefined (strict mode) or window (non-strict).

this in action

function personInfo() { return `${this.firstName} is ${this.age} years old`; } const person1 = { firstName: "harsh", age: 8, about: personInfo }; const person2 = { firstName: "nitish", age: 17, about: personInfo }; person1.about(); // this = person1 person2.about(); // this = person2
