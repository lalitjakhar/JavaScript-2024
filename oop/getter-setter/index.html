Getters & Setters — computed properties

get defines a property you read like a property (no parentheses). set lets you write to it like a property. Both run code behind the scenes.

Why? Combine or transform data on the fly. E.g. fullName computed from firstName + lastName.

Getter: read computed value

class Person { constructor(firstName, lastName, age) { this.firstName = firstName; this.lastName = lastName; this.age = age; } get fullName() { return `${this.firstName} ${this.lastName}`; } } const person = new Person("lalit", "jakhar", 18); console.log(person.fullName); // "lalit jakhar" (no parentheses)

Setter: write to split data

class Person { constructor(firstName, lastName, age) { this.firstName = firstName; this.lastName = lastName; this.age = age; } get fullName() { return `${this.firstName} ${this.lastName}`; } set fullName(fullName) { const [firstName, lastName] = fullName.split(" "); this.firstName = firstName; this.lastName = lastName; } } const person = new Person("lalit", "jakhar", 18); person.fullName = "aman sharma"; // setter console.log(person.fullName); // "aman sharma"
