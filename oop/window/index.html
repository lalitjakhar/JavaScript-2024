Step 7 · OOP Basics

Window — the global object

In browsers, window is the top-level object. Global variables and functions live on it. this at the top level equals window.

Strict mode: When you add "use strict";, this inside a plain function becomes undefined instead of window.

Checking window and this

console.log("window object:", window); console.log("this === window?", this === window);
Output…

this in strict mode

"use strict"; function myFunc() { console.log("this inside function:", this); } myFunc(); // undefined (strict mode)
Output…

Always use "use strict"; at the top of your files. It prevents accidental globals and makes this behavior more predictable.
