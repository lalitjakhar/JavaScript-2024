Prototype — functions are objects

Every function has a .prototype property (an object). You can add methods to it, and they'll be shared by all instances.

Why? Functions in JS are objects. They have properties like .name and .prototype. The prototype object is where shared methods live.

Exploring function properties

function hello() { console.log("hello world"); } console.log(hello.name); // "hello" hello.myOwnProperty = "very unique value"; console.log(hello.myOwnProperty); console.log(hello.prototype); // {}
