Step 9 · Async

fetch — get data from the internet

fetch(url) returns a Promise. Use await response.json() to extract data. Always check response.ok.

Two-step process: 1) fetch(url) → get Response object. 2) response.json() → parse JSON body. Both are async.

Load a joke from an API

async function loadJoke() { try { const response = await fetch( "https://official-joke-api.appspot.com/random_joke" ); if (!response.ok) { throw new Error(`HTTP error: ${response.status}`); } const data = await response.json(); console.log(`${data.setup} — ${data.punchline}`); } catch (error) { console.log("Could not load joke:", error.message); } } loadJoke();

Always wrap fetch in try/catch. Network errors, timeouts, and bad responses can fail. Check response.ok before parsing.
