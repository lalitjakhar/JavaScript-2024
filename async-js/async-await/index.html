Step 9 · Async

async / await — cleaner way to wait for promises

Write asynchronous code that reads top to bottom like normal code. await pauses until the promise resolves.

async function: always returns a Promise. await: only works inside async functions. Much cleaner than chaining .then().

Sequential: one after another

async function showUserPosts() { try { const user = await getUser(1); console.log("User:", user); const posts = await getPosts(user.id); console.log("Posts:", posts); } catch (error) { console.log("Error:", error.message); } } showUserPosts();

Parallel: Promise.all

When tasks don't depend on each other, run them at the same time with Promise.all.

async function loadTogether() { const [user, posts] = await Promise.all([ getUser(2), getPosts(2) ]); console.log("Loaded together:", user.name, posts.length, "posts"); } loadTogether();

Always wrap await in try/catch to handle errors. Without it, unhandled rejections crash your app.
