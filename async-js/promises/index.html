Step 9 · Async

Promises — a value that arrives later

Some work takes time (timers, API calls). A Promise says: “I’ll give you the answer when I’m done.”

Three states: pending (waiting) → fulfilled (success) or rejected (failed).

Example 1: wait, then succeed

function wait(ms) { return new Promise((resolve) => { setTimeout(() => resolve(`Waited ${ms}ms`), ms); }); } wait(800).then((msg) => console.log(msg));
Result…

Example 2: success vs failure

canVote(age) .then((msg) => console.log("Success:", msg)) .catch((err) => console.log("Fail:", err.message));
Result…

.then handles success. .catch handles errors. Always plan for both.
