const — values that don't change

Use const for values that should never be reassigned. It's your default choice — safer than let.

Why learn this? Prevents accidental changes. Most values don't need to change, so const protects your code.

1. Declare a constant

Example code

const pi = 3.14; console.log(pi);
Result…

Read const as "constant" — a value that stays the same.

2. Can't reassign

Try to change a const value and JavaScript throws an error. This is good — it catches mistakes.

const pi = 3.14; // pi = 3.15; ❌ TypeError! console.log(pi);
Result…

3. When to use const vs let

Use When Example
const Value won't change (default!) Names, config, math constants
let Value will change Loop counters, accumulators

Pro tip: Always start with const. Change to let only if you need reassignment.
