Basics · console.log

console.log — your first output

console.log() is like a print command. It shows values in the browser's console window — your way to see what's happening inside the code.

Why learn this? Debugging and testing start here. You need to see values to understand if your code works.

1. Print text

Example code

console.log("Hey Jakhar");
Result…

Strings (text) must be wrapped in "quotes" or 'quotes'.

2. Print numbers

Numbers don't need quotes. You can print calculations directly.

console.log(42); console.log(10 + 5);
Result…

3. Print multiple values

Separate values with commas to print them all at once.

console.log("Age:", 22, "Name:", "Jakhar");
Result…

Open your browser's DevTools (F12) to see the real console output.
