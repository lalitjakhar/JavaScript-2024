Basics · special types

undefined, null, BigInt

Three special types: undefined (not assigned), null (intentionally empty), and BigInt (very large numbers).

Why learn this? You'll see these in real code. Know the difference to avoid bugs.

1. undefined

A variable declared but never assigned a value is undefined.

let firstName; console.log(firstName); // undefined
Result…

undefined means "no value was set."

2. null

null means "intentionally empty" — you set it on purpose.

let firstName = null; console.log(typeof firstName, firstName); // "object" null (typeof null is a JS quirk!)
Result…

typeof null returns "object" — a famous JavaScript bug that's now permanent.

3. BigInt

For numbers larger than Number.MAX_SAFE_INTEGER (9 quadrillion). Add n suffix.

let myNumber = BigInt(12); let sameMyNumber = 12n; console.log(myNumber + sameMyNumber); // 24n
Result…

BigInt is for crypto, timestamps, large IDs. Regular numbers work for most cases.
