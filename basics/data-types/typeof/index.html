Basics · data types

typeof — check the data type

typeof tells you what kind of value you have: string, number, boolean, and more.

Why learn this? Debugging. When something goes wrong, check what type your variable is.

1. Check basic types

Example code

let age = 22; let firstName = "Jakhar"; console.log(typeof age); // "number" console.log(typeof firstName); // "string"
Result…

Primitive types: string, number, boolean, undefined, null, BigInt, Symbol

2. Convert number to string

Add "" to a number, or use String() to convert it to text.

let age = 18; age = age + ""; // or String(age) console.log(typeof age); // "string"
Result…

3. Convert string to number

Use + prefix or Number() to turn text into a number.

let myStr = "34"; myStr = +myStr; // or Number(myStr) console.log(typeof myStr); // "number"
Result…

Type conversion is common when handling user input (always starts as string).
