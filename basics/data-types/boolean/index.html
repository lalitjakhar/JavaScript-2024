Boolean — true or false

A boolean is the simplest type: true or false. Used for yes/no questions and comparisons.

Why learn this? Every decision in code comes down to true or false. if statements need booleans.

1. Comparison operators

Example code

let num1 = 9; let num2 = 7; console.log(num1 > num2); // true console.log(num1 < num2); // false console.log(num1 >= num2); // true
Result…

Comparisons: >, <, >=, <=

2. == vs ===

== checks value only (loose). === checks value and type (strict).

let num1 = 7; let num2 = "7"; console.log(num1 == num2); // true (same value) console.log(num1 === num2); // false (different types)
Result…

3. != vs !==

!= is "not equal" (loose). !== is "strictly not equal."

let num1 = 9; let num2 = 7; console.log(num1 != num2); // true console.log(num1 !== num2); // true
Result…

Pro tip: Always use === and !== to avoid surprises.
