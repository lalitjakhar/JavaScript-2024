Basics · strings

String Methods — transform text

Strings have built-in functions (methods) to clean, change case, and extract parts.

Why learn this? Clean user input, format names, validate emails, search text.

1. trim() — remove spaces

Example code

let firstName = " Jakhar "; console.log(firstName.length); // 17 firstName = firstName.trim(); console.log(firstName.length); // 6
Result…

Always trim() user input to remove accidental spaces.

2. toUpperCase() / toLowerCase()

Change case for comparisons, formatting, or shouting.

let firstName = "Jakhar"; console.log(firstName.toUpperCase()); // "JAKHAR" console.log(firstName.toLowerCase()); // "jakhar"
Result…

3. slice() — extract part

Extract a substring using start and end index.

let firstName = "Jakhar"; // J a k h a r // 0 1 2 3 4 5 let part = firstName.slice(0, 3); // "Jak" let part2 = firstName.slice(2, 5); // "kha" console.log(part, part2);
Result…

slice(start, end) — end is not included. slice(0, 3) gets indices 0, 1, 2.
