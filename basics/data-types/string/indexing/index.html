String Indexing — access individual letters

Strings are like arrays of characters. Each letter has a position (index) starting at 0.

Why learn this? Extract parts of text, check first/last characters, build validators.

1. Access by index

Example code

let firstName = "Jakhar"; // J a k h a r // 0 1 2 3 4 5 console.log(firstName[3]); // "h"
Result…

Index starts at 0, not 1. First letter is [0].

2. String length

Use .length to count characters. Useful for validation (password must be 8+ chars).

let firstName = "Jakhar"; console.log(firstName.length); // 6
Result…

3. Last character

Last index is always length - 1 (because we start at 0).

let firstName = "Jakhar"; let lastIndex = firstName.length - 1; console.log(firstName[lastIndex]); // "r"
Result…

Common pattern: str[str.length - 1] for last character.
