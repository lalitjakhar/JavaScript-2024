Template Strings — embed variables

Use backticks ` and ${} to insert variables directly into text. Much cleaner than + concatenation.

Why learn this? Build readable text with variables. The modern standard for string building.

1. Old way vs new way

Old concatenation

let firstName = "Lalit Choudhary"; let age = 22; let aboutMe = "my name is " + firstName + " and my age is " + age; console.log(aboutMe);

New template string

let aboutMe = `my name is ${firstName} and my age is ${age}`; console.log(aboutMe);
Result…

Use backticks `, not quotes. Find it under Esc key.

2. Embed expressions

You can put any expression inside ${} — calculations, function calls, etc.

let price = 100; let message = `Total: $${price * 1.2} with tax`; console.log(message); // "Total: $120 with tax"
Result…

3. Multi-line strings

Template strings preserve line breaks. No need for \n.

let message = `Line one Line two Line three`; console.log(message);
Result…

Template strings are the best practice for modern JavaScript.
