Concatenation — join strings

Use + to glue strings together. It's the old way to build text from pieces.

Why learn this? Build full names, messages, URLs. You'll see it in older code.

1. Join two strings

Example code

let string1 = "Lalit"; let string2 = "Jakhar"; let fullName = string1 + " " + string2; console.log(fullName); // "Lalit Jakhar"
Result…

Add " " to insert a space between words.

2. Convert string to number

If strings look like numbers, use + prefix to convert them before adding.

let string1 = "12"; let string2 = "18"; // "12" + "18" = "1218" (string concat) // +string1 + +string2 = 30 (number add) let newString = +string1 + +string2; console.log(newString); // 30
Result…

3. Concatenation pitfalls

Code Result Why
"12" + "18" "1218" String concat
12 + 18 30 Number addition
"12" + 18 "1218" String wins!

Modern code uses template strings (`${}`) instead of +. See next lesson!
