do-while — run at least once

do-while is like while, but it checks the condition after running the code. Guarantees at least one execution.

Why learn this? "Show menu, then check if user wants to continue" — action first, then decision.

1. Key difference

while (checks first)

let i = 10; while (i <= 9) { console.log(i); // never runs! i++; }

do-while (checks after)

let i = 10; do { console.log(i); // runs once! i++; } while (i <= 9);
Result…

do-while always runs the body at least once, even if condition is false.

2. Count 0 to 9

Normal use case where condition is true at start.

let i = 0; do { console.log(i); i++; } while (i <= 9);
Result…

3. When to use

Use When
while May not run at all (check first)
do-while Must run at least once

Common for menu loops, input validation, game loops.
