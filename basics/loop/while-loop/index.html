while loop — repeat while true

A while loop repeats code as long as a condition stays true. Simpler than for when you don't know the exact count.

Why learn this? "Keep asking for input until valid," "Process items until queue is empty."

1. Count from 0 to 9

Example code

let i = 0; while (i <= 9) { console.log(i); i++; }
Result…

Don't forget to update i inside the loop, or it runs forever!

2. Sum of first 10 numbers

Calculate 1 + 2 + 3 + ... + 10 using a loop.

let num = 10; let total = 0; let i = 0; while (i <= num) { total = total + i; i++; } console.log(total); // 55

3. while vs for

Use When
for Know exact count (iterate 10 times)
while Condition-based (repeat until valid input)

while checks the condition before each iteration.
