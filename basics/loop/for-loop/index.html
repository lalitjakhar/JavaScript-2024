Step 1 · Basics

for loop — repeat work

A loop runs the same steps many times. Useful for counting, printing lists, and checking every item.

Why learn this? Without loops you’d copy-paste the same code 100 times. A loop does it in 3 lines.

Anatomy of a for loop

Part Meaning Example
start where counting begins let i = 1
condition keep going while true i <= 5
step how i changes each time i++ (add 1)
for (let i = 1; i <= 5; i++) { console.log(i); }
Result…

i++ means i = i + 1. Each pass is one “iteration.”
