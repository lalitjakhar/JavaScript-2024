else if — multiple paths

When you have more than two choices, use else if. Check conditions one by one until one matches.

Why learn this? Grades (A/B/C/D/F), weather descriptions, pricing tiers — all need multiple branches.

1. Temperature checker

Example code

let tempInDegree = 15; if (tempInDegree < 0) { console.log("extremely cold outside"); } else if (tempInDegree < 16) { console.log("It is cold outside"); } else if (tempInDegree < 25) { console.log("Weather is Okay"); } else if (tempInDegree < 35) { console.log("lets go for swim"); } else if (tempInDegree < 45) { console.log("Ac"); } else { console.log("Too hot !!"); }
Result…

Only the first matching condition runs. Order matters!

2. Flow chart

if (condition1) { // runs if condition1 is true } else if (condition2) { // runs if condition1 false, condition2 true } else if (condition3) { // runs if both above false, condition3 true } else { // runs if all above are false }

You can have as many else if blocks as you need. The else at the end is optional.
