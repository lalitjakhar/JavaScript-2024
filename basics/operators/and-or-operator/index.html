Basics · operators

AND / OR — combine conditions

&& (AND) and || (OR) let you check multiple things at once. Essential for complex decisions.

Why learn this? "User is logged in AND has permission" or "Password is short OR contains no numbers."

1. && (AND) — both must be true

Example code

let firstName = "Jakhar"; let age = 19; if (firstName[0] === "J" && age > 18) { console.log("Name starts with J AND above 18"); } else { console.log("One condition failed"); }
Result…

&& requires both sides to be true.

2. || (OR) — at least one must be true

If either condition is true, the whole thing is true.

let firstName = "Jakhar"; let age = 19; if (firstName[0] === "J" || age > 18) { console.log("At least one is true"); } else { console.log("Both are false"); }
Result…

3. Truth table

A B A && B A || B
true true true true
true false false true
false true false true
false false false false

AND is stricter (needs all). OR is lenient (needs any).
