Ternary Operator — shortcut if/else

The ternary operator ? : is a one-line if/else. Use it for simple assignments.

Why learn this? Write clean, concise code. Perfect for picking between two values.

1. Long way (if/else)

Before

let age = 4; let drink; if (age >= 5) { drink = "coffee"; } else { drink = "milk"; } console.log(drink);
Result…

2. Short way (ternary)

After

let age = 8; let drink = age >= 5 ? "coffee" : "milk"; console.log(drink);
Result…

Format: condition ? valueIfTrue : valueIfFalse

3. When to use

Use When
Ternary Simple pick between two values
if/else Multiple lines, complex logic

Ternary is great for inline assignments, but don't nest them — gets confusing!
