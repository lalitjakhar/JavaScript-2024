Step 1 · Basics

Variables — named boxes for data

A variable is a labeled box. You put a value inside, and later you can read it or change it using the label (name).

Why learn this? Almost every program stores something — a name, a score, a count. Variables are how you remember data.

1. Create and print a variable

Example code

let firstName = "Lalit"; console.log(firstName); // → Lalit
Result…

Read it as: “make a box named firstName, put "Lalit" inside, then show what’s inside.”

2. Change the value later

With let, you can replace what’s in the box. The name stays the same.

let firstName = "Lalit"; firstName = "Jakhar"; // replace the value console.log(firstName); // → Jakhar
Result…

3. let vs const vs var

Keyword Can reassign? When to use
const No Default choice — value won’t change
let Yes When you need to update later
var Yes Old style — learn it, avoid in new code 
Result…

Names are case-sensitive: Name and name are different variables.
