Basics · let keyword

let — modern variable declaration

Use let to declare a variable that can change. It's the modern, safer way compared to the old var keyword.

Why learn this? let has block scope, which prevents many common bugs. It's the standard in modern JavaScript.

1. Declare with let

Example code

let firstName = "Jakhar"; console.log(firstName);
Result…

The keyword let tells JavaScript "create a new variable here."

2. let vs var — block scope

let is block-scoped — it only exists inside { } braces. var ignores blocks, causing confusion.

if (true) { let x = 10; var y = 20; } // x is not available here (good!) // y is still available (confusing!)
Result…

3. Best practice

Keyword Use it?
let ✅ Yes — default for variables that change
var ❌ Avoid — old style with quirks

Modern code uses let and const, almost never var.
