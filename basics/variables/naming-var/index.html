Naming Variables — the rules

Variable names have strict rules. Follow them, or your code won't run.

Why learn this? Naming mistakes cause errors. Good names also make code readable.

1. Can't start with a number

// ❌ Invalid // let 1value = 10; // ✅ Valid let value1 = 10; console.log(value1 / 2);
Result…

Names can contain numbers, just not start with them.

2. Only letters, _, and $

Use underscore _ or dollar sign $. No spaces or special characters like -, !, @.

// ✅ Valid let first_name = "Jakhar"; let _firstname = "Jakhar"; let first$name = "Jakhar"; let $firstname = "Jakhar"; // ❌ Invalid // let first-name = "Jakhar"; // let first name = "Jakhar";
Result…

3. Use camelCase

JavaScript convention: start lowercase, capitalize each new word.

Style Example Use?
camelCase firstName ✅ Standard in JS
snake_case first_name ⚠️ Works, but uncommon

Good names are clear: userAge beats x.
