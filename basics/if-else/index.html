Step 1 · Basics

if / else — make decisions

Programs choose paths. if asks a yes/no question. If yes → do A. Else → do B.

Why learn this? Logins, games, forms, prices — all need “if this, then that.”

1. Can the user play?

Real example

if (age > 18) { console.log("You can play"); } else { console.log("Play something else"); }
Result…

2. Even or odd?

% gives the remainder. If remainder is 0 when divided by 2 → even.

if (num % 2 === 0) { console.log("even"); } else { console.log("odd"); }
Result…

Always prefer === (strict equals) over ==.

3. Truthy / falsy values

Empty values are treated as “no”. Try clearing the name — the else path runs.

if (firstName) { console.log(firstName); } else { console.log("firstName is empty"); }
Result…

Falsy values: "", 0, null, undefined, false, NaN.
