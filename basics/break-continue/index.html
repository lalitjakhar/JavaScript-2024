Basics · loop control

break & continue — control loops

break exits the loop immediately. continue skips to the next iteration.

Why learn this? Stop searching when found, skip invalid items, exit early to save time.

1. break — exit loop

Example code

for (let i = 1; i <= 10; i++) { if (i === 4) { break; // stop loop here! } console.log(i); } // Output: 1 2 3
Result…

break stops the entire loop. Use it when you found what you're looking for.

2. continue — skip one iteration

continue jumps to the next loop iteration, skipping remaining code.

for (let i = 1; i <= 10; i++) { if (i === 4) { continue; // skip 4! } console.log(i); } // Output: 1 2 3 5 6 7 8 9 10
Result…

continue skips the current item but keeps looping. Use for filtering.

3. Quick comparison

Keyword Effect Example use
break Exit loop entirely Found search result, stop
continue Skip to next iteration Skip invalid/empty items

Both work in for, while, and do-while loops.
