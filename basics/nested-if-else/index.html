Nested if/else — decisions inside decisions

Put an if statement inside another. Useful when one decision depends on a previous one.

Why learn this? "If user is logged in, check if they're admin." Nested logic is everywhere.

1. Guess the number game

Example code

let winningNumber = 19; let userGuess = 17; if (userGuess === winningNumber) { console.log("YOUR GUESS IS RIGHT"); } else { // Wrong guess — check if too high or low if (userGuess < winningNumber) { console.log("too low"); } else { console.log("too high"); } }
Result…

The inner if only runs if the outer else runs first.

2. Structure

if (condition1) { // do A } else { // condition1 was false, now check condition2 if (condition2) { // do B } else { // do C } }

Avoid deep nesting (3+ levels) — use else if or functions instead to keep code readable.
