Step 8 · Resilience

Error Handling — catch problems without crashing

Wrap risky code in try/catch. If something breaks, your app keeps running and you can respond gracefully.

Why it matters: Unhandled errors crash your app. Catching them lets you show user-friendly messages, retry, or log for debugging.

try / catch

try { const data = JSON.parse("{ bad json }"); console.log(data); } catch (error) { console.log("Caught error:", error.message); }

Throwing your own errors

function divide(a, b) { if (b === 0) { throw new Error("Cannot divide by zero"); } return a / b; } try { console.log(divide(10, 2)); // 5 console.log(divide(10, 0)); // jumps to catch } catch (error) { console.log("Math problem:", error.message); }

finally — always runs
