Step 6 · Collections

Sets — unique items only

A Set is like an array but automatically removes duplicates. Perfect for tracking unique values.

Key features: iterable, no index access, no duplicates, insertion order is preserved.

Creating and adding to a Set

const numbers = new Set([1, 2, 3]); numbers.add(4); numbers.add(2); // ignored (already exists) console.log(numbers); // Set {1, 2, 3, 4}
Output…

Removing duplicates from an array

const myArray = [1, 2, 3, 3, 4, 4, 5, 5, 6, 7, 8, 8]; const uniqueElements = new Set(myArray); console.log([...uniqueElements]); // [1,2,3,4,5,6,7,8]
Output…

Check if item exists

const alphabets = new Set("abcdefghi"); console.log(alphabets.has('c')); // true console.log(alphabets.has('z')); // false

Use .has() for fast lookups, .add() to insert, .delete() to remove, and .clear() to empty the set.
