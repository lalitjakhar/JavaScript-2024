Step 6 · Safe Access

Optional Chaining — safely read nested data

Use ?. to read properties that might not exist. If any part is undefined or null, you get undefined instead of an error.

Without optional chaining: user.address.street throws an error if address is missing. With it: user?.address?.street returns undefined safely.

Safe property access

const user = { firstName: "harshit" // address is missing }; console.log(user?.firstName); // "harshit" console.log(user?.address?.houseNumber); // undefined (no error)
