DOM Events — respond to user actions

Use addEventListener to react when users click, type, hover, submit forms, etc. Events let you make pages interactive.

Pattern: element.addEventListener(eventType, callback). Common events: click, input, submit, keydown.

nameInput.addEventListener("input", (event) => { const name = event.target.value.trim(); greetEl.textContent = name ? `Hello, ${name}!` : "Hello!"; });

The event object (event or e) gives you details: target (which element), key, clientX/Y, etc.
