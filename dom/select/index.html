DOM Selection — find elements on the page

Use querySelector and querySelectorAll to find HTML elements by id, class, or any CSS selector. Then read or change them.

Common methods: getElementById, querySelector (first match), querySelectorAll (all matches). Prefer querySelector for flexibility.
