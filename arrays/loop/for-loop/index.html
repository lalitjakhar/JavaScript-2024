Arrays · loops

for loop — iterate with index

Visit every array item using for (let i = 0; i < arr.length; i++). Classic loop with full control.

When to use? When you need the index, or want to loop backwards, or skip items by step.

1. Basic for loop over an array

Start at 0, end before length, increment by 1.

Code

const fruits = ["apple", "mango", "grapes", "banana"]; for (let i = 0; i < fruits.length; i++) { console.log(fruits[i]); }

2. Transform while looping

Build a new array by processing each item.

const fruits = ["apple", "mango", "grapes", "banana"]; const upperFruits = []; for (let i = 0; i < fruits.length; i++) { upperFruits.push(fruits[i].toUpperCase()); } // → ["APPLE", "MANGO", "GRAPES", "BANANA"]

3. Loop backwards

Start at the last index, decrement until 0.

for (let i = fruits.length - 1; i >= 0; i--) { console.log(fruits[i]); }

Modern alternatives: forEach, for...of, and map are often cleaner. But for is best when you need the index or fine control.
