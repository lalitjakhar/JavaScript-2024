Arrays · loops

for...of & for...in

Two modern shortcuts: for...of loops over values, for...in loops over indexes (or keys).

Best practice: Use for...of for arrays. Avoid for...in on arrays — it can cause bugs.

1. for...of — loop over values directly

Clean syntax. No index needed. Perfect for arrays.

Code

const fruits = ["apple", "mango", "grapes"]; for (let fruit of fruits) { console.log(fruit); } // → "apple", "mango", "grapes"

for...of is the modern way to loop arrays when you don't need the index.

2. Transform with for...of

Build a new array by processing each value.

const fruits = ["apple", "mango", "grapes"]; const upperFruits = []; for (let fruit of fruits) { upperFruits.push(fruit.toUpperCase()); } // → ["APPLE", "MANGO", "GRAPES"]

3. for...in — loop over indexes (not recommended for arrays)

for...in gives you the index, not the value. It's designed for objects, not arrays.

const vegetables = ["Tomato", "Potato", "Pea"]; for (let index in vegetables) { console.log(index); // "0", "1", "2" (strings!) console.log(vegetables[index]); // "Tomato", "Potato", "Pea" }
Click to see…

⚠️ for...in returns indexes as strings, can include inherited properties, and is slower. Use for...of instead for arrays.
