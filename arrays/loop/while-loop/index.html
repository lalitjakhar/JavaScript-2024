Arrays · loops

while loop — condition-based iteration

while keeps running as long as a condition is true. You control the index manually.

When to use? Less common for arrays. for or forEach are usually clearer.

1. Basic while loop over an array

Initialize i before the loop. Increment inside.

Code

const fruits = ["apple", "mango", "grapes"]; const fruits2 = []; let i = 0; while (i < fruits.length) { fruits2.push(fruits[i].toUpperCase()); i++; }

2. Comparison: for vs while

They do the same thing, but for keeps everything in one line.

Loop type When to use
for Known number of iterations (e.g. array.length)
while Condition-based (e.g. "until user quits")
forEach Clean syntax, no index needed

3. Common mistake: infinite loop

Forgetting to increment i causes an infinite loop (browser freeze). Always ensure i++ is inside!

// ❌ DANGER: infinite loop let i = 0; while (i < fruits.length) { console.log(fruits[i]); // forgot i++ } // ✓ Correct let i = 0; while (i < fruits.length) { console.log(fruits[i]); i++; // don't forget this! }

For arrays, prefer for, forEach, or for...of — they handle the index automatically.
