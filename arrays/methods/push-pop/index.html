push & pop — change the end

Think of a queue waiting at the end of a line: push joins the end, pop leaves from the end.

Remember: Both work on the last index (length - 1. Start of the array is untouched.

Live demo

Code you’ll be running

fruits.push("mango"); // add at end, returns new length const removed = fruits.pop(); // remove from end, returns removed item
