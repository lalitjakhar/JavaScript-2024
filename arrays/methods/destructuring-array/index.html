Array destructuring

Pull out array items into separate variables in one line instead of multiple assignments.

Why? Less typing. Cleaner code. Especially helpful when functions return arrays.

1. Old way vs destructuring

Compare the old approach with the modern shortcut.

const myArray = ["value1", "value2", "value3"]; // Old way const myvar1 = myArray[0]; const myvar2 = myArray[1]; // New way (destructuring) const [myvar1, myvar2] = myArray;

2. Skip items with commas

Leave blank spots to skip array elements.

const colors = ["red", "green", "blue", "yellow"]; const [first, , third] = colors; // first = "red", third = "blue" // (skipped "green")

3. Rest operator (...)

Collect remaining items into a new array.

const nums = [1, 2, 3, 4, 5, 6]; const [first, second, ...rest] = nums; // first = 1, second = 2 // rest = [3, 4, 5, 6]

Destructuring works with function returns too: const [x, y] = getCoordinates();
