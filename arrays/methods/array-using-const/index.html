Arrays · const keyword

Arrays with const

const locks the variable name, not the array contents. You can still push, pop, and change items.

Why use const? It prevents accidental reassignment (fruits = []) but allows normal array operations.

1. const allows you to modify contents

const means "this variable always points to the same array" — but you can change what's inside the array.

Code

const fruits = ["apple", "mango"]; fruits.push("banana"); // ✓ allowed fruits[0] = "orange"; // ✓ allowed console.log(fruits); // ["orange", "mango", "banana"]

2. const prevents reassignment

You cannot point the variable to a completely new array.

const fruits = ["apple", "mango"]; fruits = ["new", "array"]; // ❌ Error! // TypeError: Assignment to constant variable.
Click to trigger error…

Use const by default. Only use let if you truly need to reassign the entire array.
