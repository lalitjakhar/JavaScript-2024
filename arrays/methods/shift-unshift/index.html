unshift & shift — change the start

Same idea as push/pop, but at the beginning (index 0).

Memory trick:
push/pop → end · unshift/shift → start
“unshift = un-shift things to make room at the front.”

Live demo

fruits.unshift("banana"); // add at start const removed = fruits.shift(); // remove from start
Ready…
Method Where Returns
unshift(x) Add at start New length
shift() Remove from start Removed item

Note: shifting re-indexes everything (old index 1 becomes 0), so it can be slower on huge arrays — but perfect for learning.
