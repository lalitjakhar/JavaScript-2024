Clone & concatenate arrays

Create true copies or merge arrays without changing the originals.

Why? Avoid accidental mutations. Keep original data safe while building new arrays.

1. Four ways to clone an array

All four methods create a new array in memory.

const array1 = ["item1", "item2"]; // 1. Spread operator (modern, recommended) const array2 = [...array1]; // 2. slice() method const array3 = array1.slice(0); // 3. concat() with empty array const array4 = [].concat(array1); // 4. Manual copy (not recommended) const array5 = ["item1", "item2"];

Best practice: use [...array] — it's short and clear.

2. Concatenate (join) two arrays

Merge multiple arrays into one new array.

const fruits = ["apple", "banana"]; const veggies = ["carrot", "potato"]; // Modern way: spread const food = [...fruits, ...veggies]; // → ["apple", "banana", "carrot", "potato"] // Old way: concat const food2 = fruits.concat(veggies);

3. Clone + add more items

You can clone and add new items in one step.

const original = ["item1", "item2"]; const expanded = [...original, "item3", "item4"]; // → ["item1", "item2", "item3", "item4"]
