sort() — arrange items in order

sort reorders the array. For numbers, you must provide a compare function or it treats them as strings.

Watch out: sort mutates the original array by default. Clone first if you need the original.

1. Sort numbers (low to high)

Use a compare function: (a, b) => a - b.

Code

const nums = [40, 5, 100, 1, 25]; // Sort ascending const sorted = nums.slice(0).sort((a, b) => a - b); // → [1, 5, 25, 40, 100]

2. Real-world: sort objects by price

Access the property in the compare function.

const products = [ { productId: 1, productName: "mobile", price: 33000 }, { productId: 2, productName: "laptop", price: 122000 }, { productId: 3, productName: "tv", price: 18000 }, { productId: 4, productName: "refrigerator", price: 12000 }, ]; // Low to high const lowToHigh = products.slice(0).sort((a, b) => a.price - b.price); // High to low const highToLow = products.slice(0).sort((a, b) => b.price - a.price);

3. Why clone first?

sort mutates the original array. Use slice(0) or [...array] to avoid side effects.

const original = [5, 2, 8, 1]; // Mutates original original.sort((a, b) => a - b); // original is now [1, 2, 5, 8] // Safe: clone first const sorted = [...original].sort((a, b) => a - b);

Compare function rules:
• Return negative → a comes before b
• Return positive → b comes before a
• Return 0 → order unchanged
