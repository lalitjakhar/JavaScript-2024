Arrays · reduce

reduce() — many values → one answer

Carry a running total (the accumulator). Visit each item, update the total, finish with one final value.

Best mental model: a piggy bank. Start with 0. Drop in each coin. End with the full sum.

Example 1: sum with every step shown

const numbers = [3, 2, 6, 8, 4, 1, 9]; const sum = numbers.reduce((total, n) => { return total + n; }, 0); // 0 is the starting total

Always pass a starting value (0 for sums) so results stay predictable.
