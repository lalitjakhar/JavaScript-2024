Arrays · some

some() — test if at least one matches

some returns true if any item passes the test. Otherwise false.

Best mental model: "Is there at least one even number?" / "Does any product cost less than $100?"

1. Basic example: even numbers

Check if the array contains at least one even number.

Code

const numbers = [3, 5, 8, 9]; const hasEven = numbers.some((number) => number % 2 === 0); // → true (because 8 is even)

2. Real-world: shopping cart check

"Is there anything in my cart under $100,000?" Useful for quick validation.

const userCart = [ { productId: 1, productName: "mobile", price: 33000 }, { productId: 2, productName: "laptop", price: 122000 }, { productId: 3, productName: "tv", price: 18000 }, { productId: 4, productName: "refrigerator", price: 12000 }, ]; const affordable = userCart.some((item) => item.price < 100000); // → true

3. some vs every

Two sides of the same coin.
