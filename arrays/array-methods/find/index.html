Arrays · find

find() — get the first match

find searches the array and returns the first item where the test returns true.

Best mental model: "Find the user with ID 3" / "Find the first word that's 3 letters long."

1. Find by condition

Pass a test function. find returns the first item that passes.

Code

const words = ["Hello", "cat", "Dog", "Lion"]; const result = words.find((word) => word.length === 3); // → "cat" (first match)

If no match is found, find returns undefined.

2. Find object by property

Very common: search an array of objects for a specific ID or property.

const users = [ { userId: 1, firstName: "jakhar", age: "18" }, { userId: 2, firstName: "arpit", age: "29" }, { userId: 3, firstName: "sunny", age: "31" }, { userId: 4, firstName: "mohit", age: "61" }, ]; const myUser = users.find((user) => user.userId === 3); // → { userId: 3, firstName: "sunny", age: "31" }

find First match (or undefined) Looking for one specific item
