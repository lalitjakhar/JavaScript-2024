Arrays · forEach

forEach() — loop without the boilerplate

forEach runs a function for each item. Cleaner than for loops when you don't need to break early.

Why forEach? Functional style. No index variables to manage. Reads like plain English.

1. Basic forEach

Pass a function. It runs once per item.

Code

const numbers = [2, 3, 6, 7, 5]; numbers.forEach(function(number) { console.log(number * 3); }); // Arrow function style numbers.forEach((number) => { console.log(number * 3); });

2. forEach with index

The callback gets (item, index) — useful when you need both.

numbers.forEach(function(number, index) { console.log(`[${index}] = ${number}`); });

3. Real-world: loop over objects

Extract data from an array of objects — very common in web apps.

const users = [ { firstName: "jakhar", age: "18" }, { firstName: "arpit", age: "29" }, { firstName: "sunny", age: "31" }, ]; users.forEach((user) => { console.log(user.firstName); });

4. Limitations

forEach cannot break or return early. Use for or for...of if you need that.
