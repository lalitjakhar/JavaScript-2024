Arrays · filter

filter() — keep only matching items

Like a sieve: each item is tested. If the test returns true, keep it. Result is a new (often shorter) array.

Best mental model: “Give me only the even numbers” / “Give me only adults” / “Give me only products in stock.”

Example: even & odd

Code

const numbers = [1, 2, 3, 4, 5, 6, 7, 8]; const evens = numbers.filter((n) => n % 2 === 0); // → [2, 4, 6, 8] const odds = numbers.filter((n) => n % 2 !== 0); // → [1, 3, 5, 7]
