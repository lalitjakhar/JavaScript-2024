Arrays · every

every() — test if all items match

every returns true only if every item passes the test. One failure → false.

Best mental model: "Are all numbers even?" / "Is every product in stock?" / "Did everyone pass the exam?"

1. Basic example: all even?

Check if every number in the array is even.

Code

const numbers = [2, 4, 6, 8, 10]; const allEven = numbers.every((number) => number % 2 === 0); // → true (all are even)

2. Real-world: validate cart

"Are all items in my cart under $30,000?" Useful for validation rules.

const userCart = [ { productId: 1, productName: "mobile", price: 33000 }, { productId: 2, productName: "laptop", price: 122000 }, { productId: 3, productName: "tv", price: 18000 }, { productId: 4, productName: "refrigerator", price: 12000 }, ]; const allAffordable = userCart.every((item) => item.price < 30000); // → false (mobile and laptop exceed 30k)

4. some vs every summary

Method Meaning Returns true if…
some "At least one" Any item passes
every "All of them" Every item passes

Both return booleans. Use them for validation, filtering logic, or conditional rendering.
