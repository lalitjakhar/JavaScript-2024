Arrays · splice

splice() — delete, insert, or replace

splice(start, deleteCount, ...items) is a powerful mutating method. It changes the original array.

Watch out: splice modifies the array in-place. Clone first if you need to preserve the original.

1. Delete items

Remove items starting at an index.

Code

const myArray = ["item1", "item2", "item3", "item4"]; // Start at index 1, delete 2 items const deleted = myArray.splice(1, 2); // deleted → ["item2", "item3"] // myArray → ["item1", "item4"]

2. Insert items (no deletion)

Set deleteCount to 0 to insert without removing.

const myArray = ["item1", "item2"]; // Start at index 1, delete 0, insert "new" myArray.splice(1, 0, "inserted item"); // → ["item1", "inserted item", "item2"]

3. Replace items (delete + insert)

Remove some items and insert new ones in their place.

const myArray = ["item1", "item2", "item3", "item4"]; // Start at 1, delete 2, insert 2 new items myArray.splice(1, 2, "insertedA", "insertedB"); // → ["item1", "insertedA", "insertedB", "item4"]

4. Parameters summary

Parameter Meaning
start Index to begin at
deleteCount How many items to remove
...items Items to insert at start

splice returns an array of deleted items. The original array is modified.
