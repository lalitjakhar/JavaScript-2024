Arrays · map

map() — transform every item

map applies a rule to each item and builds a new array of results. Length stays the same.

Best mental model: “Turn every score into a grade” / “Turn every user object into just their name.”

Example 1: square numbers

const numbers = [3, 4, 2, 7, 9]; const squared = numbers.map((n) => n * n); // → [9, 16, 4, 49, 81]

Example 2: pull names from objects

const users = [ { firstName: "jakhar", age: "18" }, { firstName: "arpit", age: "29" }, { firstName: "sunny", age: "31" }, ]; const names = users.map((user) => user.firstName); // → ["jakhar", "arpit", "sunny"]
