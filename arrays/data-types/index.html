Arrays · data types

Primitive vs Reference types

Numbers copy their value. Arrays copy their address in memory — two names can point to the same list.

Why does this matter? If you don't know about references, you can accidentally change an array in two places at once.

1. Primitive types — copies are independent

Numbers, strings, booleans: when you copy them, they are truly separate.

Code

let num1 = 6; let num2 = num1; // num2 gets its own copy num1++; // num1 = 7, num2 = 6

Primitive types: number, string, boolean, undefined, null, symbol, bigint

2. Reference types — copies share the same data

Arrays and objects: when you copy them, both variables point to the same data in memory.

let array1 = ["item1", "item2"]; let array2 = array1; // both point to same array array1.push("item3"); // both arrays now have 3 items!
Click to see what happens…

Reference types: arrays, objects, functions. They live in memory; variables hold a "pointer" to that memory location.

3. How to make a true copy of an array

Use slice() or spread [...array] to create a new array in memory.

let array1 = ["item1", "item2"]; let array2 = [...array1]; // new array array1.push("item3"); // array1 has 3 items, array2 still has 2
