Step 2 · Arrays

Arrays — numbered lists

An array stores many values in order, like seats in a row: seat 0, seat 1, seat 2…

Why arrays? Names of students, cart items, scores — anything that is a list belongs in an array.

1. Create an array (the syntax)

Square brackets [] create a list. Items are separated by commas.

Best starter example

const fruits = ["apple", "banana", "grapes"]; // index: 0 1 2 console.log(fruits[0]); // "apple" console.log(fruits.length); // 3
Click the button…

First item is always index 0. Last item is length - 1.

2. Read one item by index

Ask: “What is in box number ___?”

const item = fruits[2]; // grapes

3. Replace an item

You don’t recreate the whole list — you overwrite one seat.

fruits[1] = "mango"; // ["apple", "mango", "grapes"]
Result…

4. Mixed types & checking arrays

JS allows mixed values. To check “is this really an array?”, use Array.isArray() (not typeof).
