Step 3 · Objects

Iterate Objects

Loop over all keys and values in an object using for...in, Object.keys(), or Object.entries().

Why iterate? When you need to process every property in an object dynamically — like displaying a form or filtering data.

1. for...in loop

Loops over all keys in an object.

for (let key in person) { console.log(key, ":", person[key]); }
Result…

2. Object.keys()

Returns an array of all keys.

const keys = Object.keys(person); // → ["name", "age", "person hobbies"]
Result…

3. for...of with Object.keys()

Combine Object.keys() with for...of to loop over values.

for (let key of Object.keys(person)) { console.log(person[key]); }
Result…

4. Object.entries()

Returns an array of [key, value] pairs.

for (const [key, value] of Object.entries(person)) { console.log(`${key} =>`, value); }
