Dot & Bracket Notation

Two ways to read or write object properties: person.name (dot) or person["name"] (bracket).

When to use brackets? Keys with spaces, dashes, or when the key is in a variable — brackets are the only way.

1. Dot notation — simple keys

const person = { name: "Jakhar", age: 18 }; console.log(person.name);
Result…

2. Bracket notation — spaces or variables

const person = { "person hobbies": ["sleeping", "music"] }; console.log(person["person hobbies"]);
Result…

Dot notation won't work with spaces: person.person hobbies is invalid.

3. Dynamic key access

When the key name is stored in a variable, only brackets work.

const key = "name"; console.log(person[key]); // "Jakhar"
Result…

4. Add/update properties

person.gender = "male"; // dot person["country"] = "India"; // bracket
