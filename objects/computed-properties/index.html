Step 3 · Objects

Computed Properties

Use variables as keys when creating an object. Wrap the variable in brackets: { [keyVar]: value }.

Why computed? Build objects dynamically from user input, API responses, or any runtime data.

1. Static vs Computed

Static key

const obj = { name: "Jakhar" };

Computed key

const key = "name"; const obj = { [key]: "Jakhar" };

2. Build with computed keys

const key1 = "firstName"; const key2 = "lastName"; const obj = { [key1]: "Lalit", [key2]: "Jakhar" };
