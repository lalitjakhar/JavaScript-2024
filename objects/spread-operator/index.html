Step 3 · Objects

Spread Operator

Copy and merge objects quickly with ... syntax. { ...obj1, ...obj2 } combines all properties.

Why spread? Create new objects without mutating originals — perfect for immutable updates (like React state).

1. Copy an object

const original = { name: "Jakhar", age: 18 }; const copy = { ...original };
Result…

The copy is a new object, not a reference.

2. Merge two objects

const obj1 = { key1: "value1", key2: "value2" }; const obj2 = { key3: "value3", key4: "value4" }; const merged = { ...obj1, ...obj2 };
Result…

3. Override properties

Later properties override earlier ones.

const obj1 = { key1: "value1", key2: "value2" }; const obj2 = { key1: "OVERRIDE", key3: "value3" }; const result = { ...obj1, ...obj2 };
