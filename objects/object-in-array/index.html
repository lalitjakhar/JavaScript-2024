Step 3 · Objects

Objects in Arrays

Store a list of related objects — like users, products, or posts. Each item is an object with the same keys.

Why arrays of objects? Most real-world data looks like this: user lists, API responses, database records.

1. Create users array

const users = [ { user_id: 1, firstName: "Jakhar", gender: "male" }, { user_id: 2, firstName: "Lalit", gender: "male" }, { user_id: 3, firstName: "Kumar", gender: "male" } ];
Result…

2. Loop with for...of

Access each user object one by one.

for (let user of users) { console.log(user.firstName, user.user_id); }
Result…

3. Find by property

Use .find() to locate one user.

const found = users.find(u => u.user_id === 2);
Result…

4. Map to extract field

Get an array of just one property.

const names = users.map(u => u.firstName); // → ["Jakhar", "Lalit", "Kumar"]
