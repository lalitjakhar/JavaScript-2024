Object Destructuring

Extract properties into variables quickly: const { name, age } = person; instead of dot notation.

Why destructure? Less typing, cleaner code. Pull out exactly the fields you need.

1. Basic destructuring

const band = { bandName: "led zeppelin", famousSong: "stairway to heaven" }; const { bandName, famousSong } = band;
Result…

2. Rename variables

Use oldName: newName syntax.

const { bandName: name } = band; console.log(name); // "led zeppelin"
Result…

3. Rest operator (...)

Collect remaining properties into a new object.

const { bandName, ...restProps } = band; console.log(restProps);
Result…

4. Default values

Provide fallback if key doesn't exist.

const user = { name: "Jakhar" }; const { name, age = 18 } = user;
