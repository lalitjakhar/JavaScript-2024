Step 3 · Objects

Objects — named details

An object stores named details about one thing — like a form: name, age, hobbies. Keys label each value.

Why objects? Arrays are great for lists. Objects are great when each piece of data has a meaning (name, price, email).

1. Array vs Object

Array

Positions: 0, 1, 2…
Good for lists of same kind.

Object

Names: name, age…
Good for one thing with many fields.

2. Create a person

const person = { name: "Jakhar", age: 18, hobbies: ["sleeping", "music"] };
