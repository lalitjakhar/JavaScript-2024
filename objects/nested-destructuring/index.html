Nested Destructuring

Destructure objects inside arrays or arrays inside objects — drill down in one line.

Why nested? Real APIs return deeply nested data. Extract exactly what you need without temporary variables.

1. Array of objects

const users = [ { user_id: 1, firstName: "Jakhar", gender: "male" }, { user_id: 2, firstName: "Lalit", gender: "male" }, { user_id: 3, firstName: "Kumar", gender: "male" } ];
Result…

2. Destructure first user

const [{ firstName, user_id }] = users; // Gets firstName & user_id from first object
Result…

3. Skip elements

Use commas to skip array positions.

const [, , { gender: user3gender }] = users; // Skips first two, gets gender from third
Result…

4. Multiple values with rename

const [ { firstName: user1Name, user_id }, , { gender: user3gender } ] = users;
